# 📊 Statistics & Probability Symbol Reference Guide

A comprehensive cheat sheet for mathematical notation, Greek letters, and common statistical symbols used across Data Science and Machine Learning.

---

## 🏛️ Population vs. Sample Parameters

> **Key Rule of Thumb:** 
> * **Greek Letters** ($\mu, \sigma, \rho$) usually represent **Population Parameters** (true values of the whole dataset).
> * **Latin Letters** ($\bar{x}, s, r$) usually represent **Sample Statistics** (estimates calculated from a subset).

| Concept | Population Parameter (Greek) | Sample Statistic (Latin) | Description |
| :--- | :---: | :---: | :--- |
| **Mean** | $\mu$ (Mu) | $\bar{x}$ (x-bar) | The arithmetic average of values. |
| **Standard Deviation** | $\sigma$ (Sigma) | $s$ | Measures spread/dispersion around the mean. |
| **Variance** | $\sigma^2$ | $s^2$ | Standard deviation squared ($SD^2$). |
| **Size / Count** | $N$ | $n$ | Total number of observations/data points. |
| **Proportion** | $p$ or $P$ | $\hat{p}$ (p-hat) | Percentage or ratio of a success condition. |
| **Correlation** | $\rho$ (Rho) | $r$ | Strength and direction of a linear relationship. |

### 1. Central Tendency & Dispersion

* **$\mu$ (Mu):** Population Mean. 
  $$\mu = \frac{\sum X}{N}$$
* **$\bar{x}$ (x-bar):** Sample Mean. 
  $$\bar{x} = \frac{\sum x}{n}$$
* **$\sigma$ (Sigma):** Population Standard Deviation.
* **$s$:** Sample Standard Deviation (uses $n-1$ for Bessel's correction to remove sample bias).
  $$s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}}$$
* **$\sigma^2$ / $s^2$:** Variance.
* **$\text{IQR}$:** Interquartile Range ($Q_3 - Q_1$).

---

### 2. Hypothesis Testing & Inferential Statistics

* **$H_0$:** Null Hypothesis. The default assumption of "no effect" or "no difference."
* **$H_a$ or $H_1$:** Alternative Hypothesis. What you are trying to prove/test.
* **$\alpha$ (Alpha):** Significance level (Type I Error rate, e.g., $0.05$ or $5\%$).
* **$\beta$ (Beta):** Type II Error rate (failing to reject $H_0$ when it is false).
* **$1 - \beta$:** Statistical Power of a test.
* **$Z$:** $Z$-score (Standardized score in Standard Normal Distribution $N(0, 1)$).
  $$Z = \frac{x - \mu}{\sigma}$$
* **$t$:** $t$-statistic (Used when $\sigma$ is unknown or sample size $n < 30$).
* **$df$:** Degrees of Freedom (typically $n - 1$).
* **$p$-value:** Probability of obtaining results as extreme as observed, assuming $H_0$ is true.

---

### 3. Machine Learning & Regression Notation

* **$\hat{y}$ (y-hat):** Predicted target value generated by a model.
* **$y$:** Actual ground truth target value.
* **$e$ or $\epsilon$ (Epsilon):** Residual / Error term ($e = y - \hat{y}$).
* **$\beta_0$:** Intercept (bias term) in regression.
* **$\beta_1, \beta_2, \dots$:** Weights / Coefficients for features in regression.
* **$R^2$:** Coefficient of Determination (percentage of variance explained by the model).

---

### 4. Set Theory & Probability Notation

* **$P(A)$:** Probability of event $A$ occurring.
* **$P(A \mid B)$:** Conditional Probability (Probability of $A$ given that $B$ has occurred).
* **$\cup$:** Union (Event $A$ **OR** Event $B$).
* **$\cap$:** Intersection (Event $A$ **AND** Event $B$).
* **$\sum$ (Capital Sigma):** Summation operator (add all values together).
* **$\prod$ (Capital Pi):** Product operator (multiply all values together).
